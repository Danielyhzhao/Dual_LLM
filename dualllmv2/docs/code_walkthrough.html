313 def _heuristic_issues(code: str) -> list:
316     tree = ast.parse(code)            # 解析为 AST
320     for node in ast.walk(tree):
322         if isinstance(node, ast.ExceptHandler):
323             if node.type is None:
324                 issues.append("Avoid bare `except:` ...")
325             elif node.type.id == "Exception":
326                 issues.append("Catching broad `Exception` ...")
328         if isinstance(node, ast.While):
329             # 检查 while 条件变量是否在循环体内被重新赋值 -> 死循环风险
341                 issues.append("`while` loop ... risk of infinite loop.")
343         if isinstance(node, ast.Compare) and float 常量比较:
346             issues.append("Avoid `==` on floats; use math.isclose()")
348     for node in ast.walk(tree):
349         if isinstance(node, ast.FunctionDef):
351             if 默认参数是 list/dict/set:
353                 issues.append("Mutable default argument ...")
355             if 递归且缺 guard:
357                 issues.append("Recursive function may lack a base case")
359             if 部分路径无返回:
360                 issues.append("may not return a value")
362             if 嵌套循环 / list.index 在循环内:
363                 issues.append("O(n^2) ...")
  1. 用 Python 的 ast 模块把代码解析成抽象语法树，然后遍历节点做静态检查——这是"离线考官"的智力来源之一。
  2. 覆盖 8+ 类常见坏味：裸 except、宽异常、死循环风险、浮点 ==、可变默认参数、递归缺基线、部分路径无返回、二次复杂度隐患。
  3. _has_guard / _ends_with_return / _may_miss_return / _is_dp / _has_quadratic_hint 是辅助判定函数（第 260-310 行），如 _is_dp 识别 dp[i][j] 这种正当的二维递推，避免把它误判成 O(n²) 隐患。
  4. _analytical_issues()（第 368 行）：当结构层面没问题时，返回 4 条"分析型"建议（边界覆盖/基线初始化/复杂度/返回值一致性），模拟 LLM-1 的深度审查，保证离线也有内容可展示。
